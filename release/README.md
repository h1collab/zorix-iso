# Release media

The full `ZorixOS-0.7.iso` is 437,256,192 bytes, which exceeds GitHub's normal Git object file limit. It must be uploaded as a GitHub Release asset rather than committed to the repository.

SHA-256:

`18eee8b5137c6eabcfeaa6f526bd9613d7f9c1eda20faf774bb4cb3d08fca793`

The build also produced five split parts for fallback transfer. The current ChatGPT GitHub connector can write repository files but does not expose Release-asset upload, so the binary ISO is not falsely claimed as uploaded here.
