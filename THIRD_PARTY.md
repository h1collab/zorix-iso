# Third-party provenance and boundaries

The original Debian kernel is `/boot/vmlinuz-6.12.96+deb13-amd64` from the local Debian kernel package; it is copied byte-for-byte. No claim of a recompiled, rebadged or proprietary kernel.

The curated binary inventory is in `docs/package-inventory.json`. Copyright/license notices are preserved in the Live root. This source kit is NOT a complete corresponding-source collection for Linux, Chromium, GCC/glibc, Mesa, LLVM, Xorg, Openbox and every packaged dependency. Public redistribution requires reviewing and satisfying all applicable obligations.

Swift 6.2.1 runtime libraries came from the local Swift toolchain. Earlier Zorix 0.4 packages are local conversation artifacts preserved under `vendor/`.

No Apple Liquid Glass SDK, SwiftUI framework, Apple logo or installed system font file is included.
